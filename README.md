# NEXORA Builders

A premium, responsive construction company website created as a Week 4 web development project.

## About

NEXORA Builders is a modern construction website focused on commercial, residential, design & build, engineering, and project management services.

## Features

* Responsive design for desktop, tablet, and mobile
* Premium construction-focused UI
* 3D mouse interaction on the hero section
* Scroll reveal animations
* Project filtering
* Project details page
* Responsive mobile navigation
* Contact form with validation
* Clickable email and phone contact
* Modern dark, bronze, and architectural visual style

## Pages

* Home
* About Us
* Services
* Projects
* Project Details
* Contact
